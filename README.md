🚗 Projeto Carros — Plataforma de Venda de Veículos

📌 Sobre o projeto

Atualmente, estou desenvolvendo uma aplicação web voltada para a venda e apresentação de veículos, utilizando Python, Django e SQLite. O projeto faz parte da minha jornada de aprendizado em desenvolvimento web, permitindo colocar em prática os conhecimentos adquiridos durante meus estudos e as aulas do curso da PyCodeBR.

Neste momento, estou trabalhando na estruturação do sistema e no desenvolvimento das funcionalidades de gerenciamento de veículos, com foco no cadastro de informações, na inclusão de imagens e no registro das placas dos automóveis por meio do painel administrativo do Django.

🛠️ Tecnologias utilizadas

Python: linguagem de programação principal.

Django: framework utilizado no desenvolvimento backend.

SQLite: banco de dados responsável pelo armazenamento das informações.

HTML e CSS: tecnologias utilizadas na construção da interface, conforme o desenvolvimento do projeto.

Git e GitHub: ferramentas de versionamento e acompanhamento da evolução do código.

🚧 Desenvolvimento atual

O projeto ainda está em desenvolvimento, e as funcionalidades estão sendo implementadas gradualmente. Meu foco atual é aprimorar a estrutura administrativa, organizar os dados dos veículos e desenvolver os recursos necessários para tornar o sistema funcional.

Entre as etapas trabalhadas estão:

Estruturação dos modelos de dados.

Configuração do banco de dados SQLite.

Desenvolvimento do gerenciamento de veículos pelo painel administrativo.

Implementação dos campos para cadastro de placas e imagens.

Aprimoramento da organização e da estrutura do código.

🎯 Objetivos de aprendizagem

Além de construir uma aplicação web, este projeto tem como objetivo consolidar meus conhecimentos em Python e Django, aprofundar minha compreensão sobre bancos de dados e desenvolver habilidades práticas em programação backend.

Cada etapa representa uma oportunidade de aprender, identificar melhorias e aplicar boas práticas de desenvolvimento de software.
